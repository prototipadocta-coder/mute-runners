# 🎧 MUTE_RUNNERS - Cyberpunk Anti-Noise 3D Game

**MUTE_RUNNERS** es un juego interactivo en 3D desarrollado con Three.js y Web Audio API, diseñado para concienciar sobre la contaminación auditiva con una estética cyberpunk estilo *Hi-Fi Rush* y *Jet Set Radio*.

## 🚀 Despliegue Rápido en Vercel

### Opción 1: Desde la Web de Vercel (Recomendada)
1. Extrae este archivo ZIP.
2. Sube la carpeta extraída a tu cuenta de **GitHub** (crea un nuevo repositorio).
3. Entra a [Vercel](https://vercel.com) e inicia sesión.
4. Haz clic en **"Add New..."** -> **"Project"**.
5. Selecciona el repositorio de GitHub de `mute-runners`.
6. Presiona **"Deploy"**. ¡Listo! Tu juego estará en vivo con un enlace HTTPS.

---

### Opción 2: Usando Vercel CLI (Línea de Comandos)
1. Instala el CLI de Vercel si no lo tienes:
   ```bash
   npm i -g vercel
   ```
2. Navega a la carpeta del proyecto en tu terminal:
   ```bash
   cd mute-runners
   ```
3. Ejecuta el comando:
   ```bash
   vercel
   ```
4. Sigue las instrucciones en pantalla para completar el despliegue en segundos.

---

## 🎮 Controles de Juego
* **W A S D** / **Flechas**: Moverte por Neo-Decibel.
* **MOUSE**: Mirar alrededor.
* **CLIC IZQUIERDO**: Disparar pulso de cancelación de fase (Null-Emitter).
* **ESPACIO**: Salto antigravedad.

---

## 💻 Tecnologías Utilizadas
* **Three.js**: Renderizado 3D en tiempo real (WebGL).
* **Web Audio API**: Síntesis de sonido dinámica sin dependencias externas.
* **CSS3 Cyberpunk Design**: UI estilizada con respuesta a pantalla completa.
